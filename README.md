# 不具合連絡シート（GitHub版）

画面は GitHub Pages、データは今までどおり Google スプレッドシートに保存します。
GAS は「データの受付係」だけを担当します。

```
[ブラウザ] ──開く──▶ GitHub Pages（index.html / config.js）
     │
     └─保存・読込─▶ GAS（Code.gs）──▶ スプレッドシート（今のシートそのまま）
```

---

## 用意するファイル

| ファイル | 置き場所 | 内容 |
|---|---|---|
| `Code.gs` | **GAS だけ**（GitHubには上げない） | データの受付係。PINや人名が入っている |
| `index.html` | GitHub | 画面本体 |
| `config.js` | GitHub | GAS の URL を1行だけ書く |
| `README.md` | GitHub | この手順書 |

---

## STEP 1　GAS 側を「受付係」に作り替える（約10分）

1. 今の不具合連絡シートのスプレッドシートを開く
2. メニュー「拡張機能」→「Apps Script」
3. 左の `コード.gs`（または `Code.gs`）を開き、**中身を全部消して** 新しい `Code.gs` の中身を貼り付ける
4. 上のほうにある次の行を書き換える

   ```js
   APP_KEY: 'ここを変更してください',
   ```
   → 例：`APP_KEY: 'hlc2026fuguai',`
   これが **共有パスワード** です。8文字以上の英数字にして、使う人にだけ口頭などで伝えてください。

5. 左の `index.html` は不要になります（消しても残しても動作に影響なし）
6. 💾 保存
7. 右上「デプロイ」→「新しいデプロイ」
   - 種類の選択（⚙）：**ウェブアプリ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 「デプロイ」→ 許可を求められたら自分のアカウントで承認
8. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピーしておく
9. 確認：その URL をブラウザで開いて、次のような文字が出れば OK
   ```
   {"ok":true,"message":"不具合連絡シートAPIは動いています"}
   ```

> ⚠ 「アクセスできるユーザー」に **全員** が出てこない場合は、会社の Google 管理者が制限しています。その場合はこの方式が使えないので相談してください。

> 💡 古い GAS 版の画面も、移行が終わるまではそのまま使えます（同じシートに書き込みます）。全員が新しい URL に移ったら「デプロイを管理」で古いデプロイをアーカイブしてください。

## STEP 2　GitHub に画面を置く（約10分）

### 2-1. アカウントを作る（まだの人だけ）
https://github.com を開き「Sign up」から作成。ユーザー名は URL の一部になります（例：`hika-hlc`）。

### 2-2. リポジトリ（= GitHub 上のフォルダ）を作る
1. 右上の「＋」→「New repository」
2. Repository name：`defect-sheet`（好きな名前でOK。半角英数字とハイフン）
3. **Public** を選ぶ（無料プランで GitHub Pages を使うには公開が必要）
4. 「Create repository」

### 2-3. ファイルを入れる
1. 作ったリポジトリの画面で「uploading an existing file」のリンクをクリック
2. `index.html`・`config.js`・`README.md` の3つをドラッグ＆ドロップ
3. 下の「Commit changes」を押す

### 2-4. GAS の URL を設定する
1. リポジトリ内の `config.js` をクリック → 右上の ✏（鉛筆）
2. `API_URL: ''` の `''` の中に STEP 1 でコピーした URL を貼る
   ```js
   API_URL: 'https://script.google.com/macros/s/AKfycb……/exec'
   ```
3. 「Commit changes」

### 2-5. 公開する
1. リポジトリ上部の「Settings」→ 左メニュー「Pages」
2. Source：**Deploy from a branch**
3. Branch：**main**、フォルダ：**/(root)** →「Save」
4. 1〜2分待つと上部に URL が出ます
   `https://ユーザー名.github.io/defect-sheet/`
   **これが今後みんなが開く URL です。**

---

## STEP 3　使い始める

1. 上の URL を開く
2. 「共有パスワード」と「名前」を入力 →「はじめる」
   （端末に記憶されるので、次回からは不要）
3. 入力した名前は `_変更履歴` シートの「実行者」に記録されます
4. 名前やパスワードを変えたいときは、画面右上の 👤 ボタン

---

## あとから修正するとき

| 直したいもの | やること |
|---|---|
| 画面（index.html） | GitHub でファイルを ✏ 編集 →「Commit changes」。1〜2分で反映 |
| GAS（Code.gs） | 保存後「デプロイ」→「デプロイを管理」→ ✏ → バージョン「新バージョン」→「デプロイ」（**URLは変わりません**） |
| 選択肢・時給 | 今までどおり画面の「🔒 編集」から（管理者PIN） |
| 共有パスワード | Code.gs の `APP_KEY` を変えて新バージョンでデプロイ → 各自 👤 から入れ直し |

---

## 困ったとき

| 症状 | 原因と対処 |
|---|---|
| 「config.js に GAS のURL…」と出る | STEP 2-4 の URL 貼り付けがまだ / `/exec` で終わっていない |
| 「通信できませんでした」 | ネット接続、または GAS のアクセス設定が「全員」になっていない |
| 「サーバーの応答が読めません」 | URL が間違っている（`/dev` ではなく `/exec` を使う） |
| 「共有パスワードが違います」 | パスワードの入力ミス。管理者に確認 |
| 「APP_KEY を設定してください」 | Code.gs の APP_KEY を変更していない |
| 「10分ほど受付を止めています」 | パスワード間違いが20回続いた。10分待つ |
| 直したのに画面が古いまま | Ctrl + F5（スマホはタブを閉じて開き直す） |

## バックアップと復元

スプレッドシートを開くとメニューに **「不具合シート管理」** が出ます。

- スナップショットを今すぐ作成
- 削除バックアップから戻す
- 変更履歴から本体を作り直す

毎日の自動バックアップは、Apps Script 左メニュー「トリガー」→「トリガーを追加」
→ 関数 `スナップショット作成` / 時間主導型 / 日付ベースのタイマー / 午前0時〜1時

---

## 公開について（大事）

- GitHub（Public）に置いた **画面のコードは誰でも見られます**。
- ただし **データ・人名・時給はスプレッドシート側** にあり、共有パスワードがないと読み書きできません。
- `Code.gs` には PIN や人名が入っているので **GitHub には上げないでください**。
- 会社のルールで外部サービスの利用に申請が必要な場合は、先に確認してください。
